# Sobre
A Universidade de Segurança Cibernetica é uma lista selecionada de recursos educacionais incríveis e gratuitos com foco em aprender fazendo.

O curso é dividido em seis partes.

Introdução e Segurança Cibernetica
Red Team - Curso Iniciante Gratuito
Blue Team - Curso Iniciante Gratuito
Prática Bônus de CTF e Útimos CVEs
Bônus Windows
Salas Extremamente Difíceis de Fazer - As tarefas são lineares em natureza de dificuldade. Então é recomendado fazê-las em ordem. Mas você ainda pode pular e pular algumas salas se achar que já está familiarizado com os conceitos.

Conforme você avança no curso, você encontrará emblemas de conclusão que estão ocultos neste README.md para emblemas de conclusão do caminho de Red e Blue Team. Você pode copiar o código HTML para eles e adicioná-lo à página de conteúdo abaixo depois de concluí-los.
